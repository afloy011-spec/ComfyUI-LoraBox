# Design — source of truth

The canonical visual design lives in **Figma** (not in this repo):

> **Lora Box — Node Design**
> https://www.figma.com/design/f2nLY8ekQR4XblKX19KkI3

The Figma file holds the explored directions and the agreed final node:

- **Current** — the original generic ComfyUI-blue card (baseline).
- **Console / Glass / Studio** — three explored visual languages.
- **Row variations (A–H)** — the LoRA-row layout study.
- **Full node (canon)** — the shipped design: **G rows** (numeric-hero strength +
  whole-box "meter" fill + full-height cover preview) in a **Glass + Console**
  (translucent + warm amber) node, with a full-node background image/video.

When the look changes, change Figma first, then mirror here. See
[INTERACTIONS.md](INTERACTIONS.md) for behaviour that a static mock can't show.
